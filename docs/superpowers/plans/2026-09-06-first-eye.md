# First Eye Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first Vintage Story observation vertical slice: `GET /v1/state` from an external localhost client.

**Architecture:** Keep HTTP transport independent of Vintage Story internals. Dispatch every game-state read to the VS main thread, snapshot into immutable protocol DTOs, then serialize on the request thread.

**Tech Stack:** C# / .NET 10, Vintage Story `VintagestoryAPI.dll`, `HttpListener`, `System.Text.Json`, Python stdlib probe.

**Spec:** `docs/superpowers/specs/2026-09-06-first-eye-design.md`

## Global Constraints

- Client mod only.
- Only `GET /v1/state`.
- Bind only `127.0.0.1:42420`.
- Do not commit proprietary Vintage Story binaries.
- No MCP, actions, movement, WebSocket, auth, scans, screenshots, GUI, or server mod.
